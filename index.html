回测口径与限制

t 日收盘信号，t+1 开盘建仓，t+n+1 开盘卖出。每组独立记账，每日新批次预算为当时净值的 1/n（含买入费用），组内等额买入后固定股数；现金不足时按可用现金执行，不融资。交易日按导入行情的日期并集计算。

区间起点空仓，逐日建立重叠持仓；区间末日统一平仓，末期批次可能不足 n 天。按每日开盘市值记账，买卖分别按实际成交额收取单边费用。无信号时保留现金，不删除收益日期。持仓开盘价缺失时停止回测，不补价、不依据未来价格筛选建仓股票。

RankIC 使用当日有效因子与可得开盘价、持满 n 天的毛收益计算；缺失终点价格的 IC 样本单独剔除，不影响建仓。并列排名取平均，至少 3 只股票且两端排名非恒定；未到期窗口不纳入。累计 RankIC 为算术和，不是收益率。

不模拟涨跌停、停牌执行、滑点、历史成分与融券。最高−最低是两组日收益差的诊断曲线，非实际多空账户。年化按 252 个交易日、无风险利率为 0。固定演示股票池有幸存者偏差，不等同于完整可交易策略。

数据接口

接口需允许浏览器跨域访问（CORS），返回 CSV 或 JSON 行情。合并更新以 (date, code) 为键，同键数据整行替换；新旧数据须使用相同复权锚点和单位。

接口返回示例

[{"date":"2026-09-10","code":"000001","open":11.68,"close":11.85}]

也支持 {"data":[...]}、{"rows":[...]}、{"fields":["date","code","open","close"],"items":[...]}。其他字段同 CSV。上例仅说明格式，不是自动更新地址。调用接口只请求行情，不上传本机已有数据。

数据格式与接入说明

必需字段：date,code,open,close。其他因子可使用 high,low,volume,amount。也支持“日期、代码、开盘、收盘、最高、最低、成交量、成交额”。价格需为一致复权口径。

日期格式 YYYY-MM-DD；代码保留六位。单股票文件可省略 code，文件名需为 000001.csv。股票池就是导入的股票集合；请自行控制历史样本偏差。支持文件、目录与标准 HTTP 数据接口；各数据商的私有格式需在接口端适配。浏览器要求先用选择器授权文件夹，不能仅凭任意绝对路径读取本机文件；刷新后需重新选择目录。

空值保留为缺失；重复日期与代码、非法价格会报错。不设置文件大小或导入行数上限；后台逐个文件读取，实际规模受浏览器内存与计算能力影响。选择新数据会替换本次数据。导入前请保留因子预热期。
